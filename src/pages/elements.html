UI Elements Library

10 essential components for web interfaces

← Back to Home

1. Radiobutton

Used when a user needs to select exactly one option. Showing default, checked, and disabled states.

2. Checkbox

Allows the user to select one or more independent options. Showing all states.

3. Text input & Textarea

Provides fields for users to enter free-form text. Includes a resizable text area.

4. Tabs

Used to alternate between different views or data sets within the same context.

5. Button

Triggers an action or event. Includes primary, secondary, selected , and disabled states.

6. Text label

Provides a clear text description or instruction tied to a specific input field.

7. Link

Navigates the user to external resources and cool websites.

GitHub ↗ CodePen ↗

8. Tooltip

Displays brief, contextual text when hovering over an element to provide additional information.

Hover over me! I am a helpful tooltip!

9. Dropdown list

Allows users to choose one value from a collapsible list of options to save space.

10. Data grid

Displays complex data in a structured, tabular format with rows and columns for easy scanning.
